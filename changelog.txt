Village Diplomacy — Changelog
================================

v1.5.0 — "Diplomacy Between Villages"
---------------------------------------

New Features:
• Village-to-village diplomatic system
  - Diplomatic state per village pair (peace, tension, crisis, ultimatum,
    mobilization, war, siege, truce and occupation)
  - Grievances: each village remembers what you did to it and uses it as casus belli
  - War declarations and ultimatums, with a village leader who decides
  - Active war: mobilization by bell, civilians taking shelter and a strength tracker
  - Three-day truce with residual consequences and war memory
  - New commands: /diplomacy grievances, warreadiness, declare, ultimatum,
    war, peace, state, setstate and settension
• Village-to-village relationships (-100..100) and editable village names
• Villagers with names, traits and emotions of their own, plus personal trade prices
• Iron golems with names, temperaments and creation stories
• Last will: a villager who dies leaves a note with their name, trade and final words
• Full Russian translation on top of English and Spanish
• 12 ranks, from LEGENDARY HERO to WANTED CRIMINAL, with discounts or penalties
• 71 configuration options to tune every value, threshold and module

Ports:
• NeoForge 1.20.1
• Forge, Fabric and Quilt 1.20.1 brought up to date with the same code
• NeoForge 1.21.0
• Forge, NeoForge, Fabric and Quilt for 1.21.1 (Java 21)

v1.4.0 — "Innkeeper, Witnesses & NeoForge"
-------------------------------------------

New Features:
• Innkeeper & Hostal system
  - Each village elects an innkeeper with a name and level
  - Sleep in hostal beds for 1 emerald (free with reputation >= 100)
  - Proximity messages entering/leaving the hostal area
• Witness system (line of sight)
  - Crimes only count if a villager actually sees you
  - Ignite TNT: -10, arm TNT: -20, explosion: -50, lava: -25
  - Hostile mob kills also require a witness to grant reputation
  - Extinguishing village fires: +3 if witnessed
• Farming is now welcome
  - Plant crops: +2, harvest/bonemeal: +1 each
• New commands
  - /diplomacy setrep <player> <amount>
  - /diplomacy gift [amount]
  - /diplomacy list and /diplomacy info improved
• Dialog colors refreshed across all messages
• MCA Reborn compatibility (guards react to reputation)
• NeoForge 1.20.1 support
• Config overhaul: all reputation values configurable + new sections (decay, notifications, modules)

Fixes:
• TNT/lava underground without witnesses no longer penalizes
• Hostile kills underground no longer grant reputation without witnesses
• Farming no longer lowers reputation (it now raises it)

v1.3.0 — "Guard Villagers & Custom Villages"
---------------------------------------------

New Features:
• /diplomacy claim <name> — Create your own village anywhere!
• /diplomacy unclaim — Remove your claimed village
• Custom village radius configurable (16-128 blocks, default 48)
• Guard Villagers full compatibility integration
  - Guards react to your village reputation upon entry
  - Guards act as witnesses: extra reputation when you kill hostile mobs near them
  - Attack/kill penalties for guards are now configurable
  - Welcome message when Guard Villagers mod is detected
• enableEntryMessages config to disable entry/exit banners
• New config section: [guard_villagers] with 4 options
  - attackGuard penalty (default -5)
  - killGuard penalty (default -100)
  - witnessBonus (default +3)
  - welcomeMessage (default true)

Fixes:
• Fixed custom village name not displaying in entry/exit messages
• Fixed village detection radius being too large for custom villages
• Guard attack/kill penalties now use config values instead of hardcoded numbers

v1.2.0 — "Personalities & Diplomacy"
